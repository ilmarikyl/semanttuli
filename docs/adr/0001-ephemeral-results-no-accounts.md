# Results are ephemeral and there is no Account

The daily Leaderboard is communal without login. A Result is an opt-in snapshot (Name or Anonymous, guess count, hint count, outcome) stored only until the next 00:00 UTC+3 day, then deleted. There is no Account, profile, or durable identity: a Name labels that day's Result, not a person we remember. The alternative was accounts (rejected: the product should not hold user data in the cloud) or a fully client-side board (rejected: it would not be shared).
