# How Place is ordered on the Leaderboard

Place is a single day's ranking, not Guess Rank (percentile closeness to the Secret word). Wins occupy the Places above all Give-ups. Wins sort by fewer guesses, then fewer hints, then earlier Result. Give-ups sort by closest typed Guess (Hints ignored: highest Rank, then highest similarity), then earlier Result. Ties never share a Place. The alternative was a combined score or ranking Give-ups by guess count, which would let a quick Give-up beat a long Win, or would reward Hint use on a Give-up.
